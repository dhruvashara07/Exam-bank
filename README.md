# exam-bank

Private question bank for Dhruv's classes. Phase 1: Cambridge IGCSE Physics 0625, 2025–2026.

- `raw/<syllabus>/<year>-<session>/` original question papers (`qp_*`) and mark schemes (`ms_*`). Sessions: FM = Feb/Mar, MJ = May/Jun, ON = Oct/Nov.
- `pipeline/` extraction scripts (coming next)
- `data/` one JSON file per question (coming next)
